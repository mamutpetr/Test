# Magnetic UI для Android

Інтерфейс, що реагує на звичайний магніт: поле вводу, кнопка й «залізні ошурки» на фоні
тягнуться до магніту, кнопка світиться з боку магніту, а стрілка повертається до нього.

## Як встановити

1. Відкрийте на телефоні реліз **magnetic-ui-latest** у розділі *Releases* репозиторію
   (або артефакт `magnetic-ui-apk` в останньому запуску *Actions*).
2. Завантажте `magnetic-ui.apk` і встановіть (Android попросить дозволити встановлення
   з цього джерела).

Потрібен Android 8.0+ з магнітометром (компасом) — він є майже в усіх смартфонах.

## Як користуватися

1. Покладіть телефон на стіл, магніт тримайте подалі й запустіть застосунок — він за пів
   секунди запам'ятає «фон» (магнітне поле Землі + власне поле телефона).
2. Натисніть **Навчити** і пройдіть 9 точок: підносьте магніт до кожної позначки й тримайте,
   поки коло не заповниться. Модель зберігається на телефоні.
3. Водіть магнітом біля телефона.

Кнопки: **Фон** — перевиміряти фон (магніт приберіть), **Полярність** — розвернути напрям
у ненавченому режимі, **Debug** — показати сирий вектор поля й оцінку позиції.

Найкраще працює невеликий неодимовий магніт на відстані 1–10 см.

## Як це працює

- `magnet/MagnetSensor.kt` читає `TYPE_MAGNETIC_FIELD_UNCALIBRATED` (калібрований сенсор
  Android поступово «вчиться» ігнорувати магніт) і `TYPE_GAME_ROTATION_VECTOR` (гіроскоп).
- `magnet/Baseline.kt` зберігає поле Землі у світових координатах і повертає його в систему
  координат телефона, тож поворот телефона не виглядає як магніт. Різниця між показом сенсора й
  фоном — це поле самого магніту (µT).
- `magnet/MagnetModel.kt` — маленька модель (ядерний k-найближчих сусідів), що з напрямку й
  сили поля оцінює, де на екрані магніт. Навчається прямо на телефоні. Без навчання працює
  приблизна евристика.
- `ui/MagneticField.kt` — модифікатори Compose `magnetic()`, `magneticGlow()` і
  `pointAtMagnet()`, які можна чіпляти до будь-якого елемента.

## Збірка

APK збирає GitHub Actions (`.github/workflows/magnetic-ui.yml`). Локально:

```bash
cd magnetic-ui
./gradlew testDebugUnitTest assembleDebug
# app/build/outputs/apk/debug/app-debug.apk
```
