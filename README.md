# Таксі — застосунки для клієнтів і водіїв

Два невеликі веб-застосунки на чистому HTML/CSS/JS без бекенду:

- `client/` — застосунок клієнта: замовлення поїздки, ціна, статус, скасування.
- `driver/` — застосунок водія: профіль, вихід на лінію, черга заявок,
  проведення поїздки від «прийнято» до «завершено», історія й заробіток.
- `shared/` — спільне «сховище» через `localStorage` та стилі.
- `index.html` — стартова сторінка з посиланнями на обидва застосунки.

## Як запустити локально

Потрібен будь-який статичний сервер, тому що застосунки використовують
ES-модулі (`<script type="module">`), а браузер не дозволяє їх завантажувати
з `file://`.

```bash
# з кореня репозиторію
python3 -m http.server 8080
```

Далі відкрийте у браузері:

- `http://localhost:8080/` — головна.
- `http://localhost:8080/client/` — клієнт.
- `http://localhost:8080/driver/` — водій.

Найкраще одразу відкрити клієнта і водія у двох сусідніх вкладках, щоб бачити,
як події з’являються з обох боків.

## Як це працює

Замість справжнього бекенду обидва застосунки читають і пишуть в один запис
`localStorage` (`taxi_state_v1`). Синхронізація між вкладками — через подію
`storage`, всередині вкладки — через власну подію `taxi:changed`.

Життєвий цикл поїздки:

```
requested → accepted → arrived → started → completed
                                          ↘ cancelled (у будь-який момент)
```

- Клієнт створює замовлення зі статусом `requested`.
- Онлайн-водій приймає заявку → `accepted`.
- Водій відмічає прибуття → `arrived`, старт → `started`, завершення → `completed`.
- Ціна рахується як `40 ₴ + 15 ₴/км` (див. `shared/store.js`).

## Обмеження

Це навчальне демо: немає справжньої мапи, GPS і платежів; «відстань» —
детермінований псевдорозрахунок від тексту адрес, щоб оцінка була стабільною.
Достатньо, щоб побачити повний потік «клієнт ↔ водій» без сервера.

## Magnetic UI (`magnet/`)

Мобільна сторінка, інтерфейс якої реагує на справжній магніт поруч із телефоном: поле вводу,
кнопка, літери заголовка й «залізні ошурки» на фоні тягнуться до магніту, кнопка світиться
з його боку, а стрілка повертається до нього.

Звідки сторінка бере дані (вибирає найкраще доступне):

1. **Магнітометр** (Generic Sensor API): повний вектор поля в µT. У Chrome на Android
   треба увімкнути `chrome://flags/#enable-experimental-web-platform-features`
   (окремий прапорець `#enable-generic-sensor-extra-classes` прибрали в Chrome 138).
2. **Компас** (`deviceorientationabsolute`, на iPhone `webkitCompassHeading`): працює без
   прапорців, але бачить лише напрям, на який магніт відхилив стрілку, тому точність нижча.
3. **Палець або миша**: якщо датчиків немає, «магнітом» стає дотик.

Як працює:

- Фон (поле Землі й телефона) запам'ятовується на старті та повертається за гіроскопом,
  тож поворот телефона не схожий на магніт. Різниця з фоном — це поле магніту.
- Позицію магніту на екрані оцінює маленька модель (ядерний k-найближчих сусідів).
  Кнопка «Навчити» дає показати магніт у 9 точках. Модель зберігається в `localStorage`.
  Без навчання працює приблизна евристика.
- Код: `magnet/magnet.js` (датчики, фон, модель), `magnet/app.js` (анімація й навчання).

Датчики працюють лише через HTTPS (або `localhost`), тож на телефоні відкривайте сторінку
з GitHub Pages чи іншого HTTPS-хостингу.
